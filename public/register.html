📋 วัตถุประสงค์การเก็บรวบรวมข้อมูล

บริษัทฯ เก็บรวบรวมข้อมูลส่วนบุคคลของท่านเพื่อวัตถุประสงค์ดังต่อไปนี้

  • แจ้งเตือนสถานะการซ่อมและบริการรถยนต์ของท่านผ่านทาง LINE
  • จัดการระบบคิวและติดตามงานซ่อมภายในสาขา
  • ติดต่อสื่อสารกับท่านเกี่ยวกับการให้บริการ
  • จัดทำประวัติการใช้บริการเพื่อพัฒนาคุณภาพการให้บริการ

📁 ข้อมูลที่บริษัทฯ เก็บรวบรวม

  • เลขทะเบียนรถ — เพื่อระบุรถของท่านในระบบ
  • จังหวัดของทะเบียนรถ — เพื่อประกอบการระบุตัวรถ
  • เบอร์โทรศัพท์ — เพื่อการติดต่อกรณีจำเป็น
  • LINE User ID — เพื่อส่งการแจ้งเตือนสถานะผ่าน LINE
  • ข้อมูลการใช้บริการ — ประเภทงานซ่อม วันเวลา สาขาที่ใช้บริการ

🏢 การเปิดเผยข้อมูลแก่บุคคลที่สาม

บริษัทฯ อาจเปิดเผยข้อมูลของท่านแก่

  • สาขาในเครือ Bridgestone A.C.T ที่ท่านใช้บริการ
  • ผู้ให้บริการระบบ (LINE Corporation, Cloudinary, Supabase) ภายใต้มาตรฐานความปลอดภัยที่เข้มงวด
  • หน่วยงานราชการเมื่อมีคำสั่งตามกฎหมาย
บริษัทฯ ไม่มีนโยบายขายหรือเปิดเผยข้อมูลส่วนบุคคลของท่านแก่บุคคลภายนอกเพื่อวัตถุประสงค์ทางการค้า

⏱ ระยะเวลาการเก็บรักษาข้อมูล

บริษัทฯ จะเก็บรักษาข้อมูลส่วนบุคคลของท่านตราบเท่าที่จำเป็นสำหรับวัตถุประสงค์ที่ระบุไว้ข้างต้น โดยทั่วไปไม่เกิน 3 ปี นับจากวันที่ใช้บริการครั้งสุดท้าย หรือตามที่กฎหมายกำหนด

✅ สิทธิ์ของท่านในฐานะเจ้าของข้อมูล

ภายใต้พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ท่านมีสิทธิ์ดังต่อไปนี้

  • สิทธิ์ในการเข้าถึงข้อมูล — ขอดูข้อมูลที่บริษัทฯ เก็บไว้เกี่ยวกับท่าน
  • สิทธิ์ในการแก้ไขข้อมูล — ขอแก้ไขข้อมูลที่ไม่ถูกต้อง
  • สิทธิ์ในการลบข้อมูล — ขอให้ลบข้อมูลของท่านออกจากระบบ
  • สิทธิ์ในการถอนความยินยอม — ถอนความยินยอมได้ตลอดเวลา โดยไม่กระทบต่อการประมวลผลที่ผ่านมา
  • สิทธิ์ในการโอนย้ายข้อมูล — ขอรับข้อมูลในรูปแบบที่สามารถนำไปใช้ต่อได้
  • สิทธิ์ในการคัดค้านการประมวลผล — คัดค้านการใช้ข้อมูลในกรณีที่กฎหมายกำหนด

📞 ช่องทางติดต่อเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล

หากท่านมีคำถามหรือต้องการใช้สิทธิ์ใดๆ กรุณาติดต่อ

  • บริษัท บริดจสโตน เอ.ซี.ที (ประเทศไทย) จำกัด
  • 14/3 หมู่ 1 ถนนพหลโยธิน ตำบลคลองหนึ่ง อำเภอคลองหลวง จังหวัดปทุมธานี 12120
  • ผ่านสาขาที่ท่านใช้บริการ หรือผ่าน LINE OA ของสาขา

🔐 ความปลอดภัยของข้อมูล

บริษัทฯ ใช้มาตรการรักษาความปลอดภัยทางเทคนิคและองค์กรที่เหมาะสมเพื่อปกป้องข้อมูลส่วนบุคคลของท่านจากการเข้าถึง การใช้ การเปิดเผย การแก้ไข หรือการทำลายโดยมิชอบ
